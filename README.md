# VHDL Digital Design

A collection of digital logic designs and simulations
developed using VHDL and Xilinx Vivado.

## Tools and Technologies

- VHDL
- Xilinx Vivado
- RTL Design
- Behavioral Simulation

## Projects

### 01. Basic Logic Gates

**AND Gate**

- Implemented a 2-input AND gate using VHDL.
- Used RTL architecture.
- Created a testbench to verify all four input combinations.
- Verified the expected output using behavioral simulation.

## Learning Objectives

- Understand VHDL syntax and design structure.
- Learn RTL modelling.
- Develop testbenches.
- Perform behavioral simulation.
- Progress towards combinational and sequential circuit design.
